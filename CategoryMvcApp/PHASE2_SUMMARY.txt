  CRITICAL CONFIGURATIONS
───────────────────────────────────────────────────────────────────────────────────

DATABASE INTEGRITY:
  ✓ Unique Index: BookedSeat(ShowId, SeatNumber)
    Purpose: Prevents booking same seat twice in same show
    Error: DbUpdateException if duplicate (ShowId, SeatNumber) inserted

  ✓ Unique Index: SeatPrice(ShowId, Category)
    Purpose: Only one price per category per show

  ✓ Unique Index: Screen(TheatreId, Name)
    Purpose: No duplicate screen names per theatre

  ✓ Unique Index: Theatre(Name, City)
    Purpose: No duplicate theatre entries

CASCADE DELETE:
  ✓ Movie → Shows (delete movie = delete all shows)
  ✓ Show → BookedSeats, SeatPrices, Bookings
  ✓ Theatre → Screens
  ⚠ User → Bookings (be careful with production data!)

PASSWORD POLICY:
  ✓ Minimum 6 characters
  ✓ Must contain: digit, non-alphanumeric, uppercase, lowercase
  ✓ Examples: "Admin@123!", "TestUser#456"

LOCKOUT POLICY:
  ✓ 5 failed attempts → 5 minute lockout
  ✓ Brute-force protection

───────────────────────────────────────────────────────────────────────────────────
  EXAMPLE: QUERYING AFTER MIGRATION
───────────────────────────────────────────────────────────────────────────────────

// Get all active movies
var movies = await db.Movies
    .Where(m => m.IsActive)
    .OrderByDescending(m => m.CreatedAt)
    .ToListAsync();

// Get all shows for a movie with seat prices
var showsWithPrices = await db.Shows
    .Where(s => s.MovieId == movieId && s.IsActive)
    .Include(s => s.SeatPrices)
    .OrderBy(s => s.StartDateTime)
    .ToListAsync();

// Get booked seats for a show
var bookedSeats = await db.BookedSeats
    .Where(bs => bs.ShowId == showId && bs.IsActive)
    .Select(bs => bs.SeatNumber)
    .ToListAsync();

// Get user's booking history
var userBookings = await db.Bookings
    .Where(b => b.UserId == userId && b.IsActive)
    .Include(b => b.Show)
    .ThenInclude(s => s.Movie)
    .Include(b => b.BookedSeats)
    .OrderByDescending(b => b.CreatedAt)
    .ToListAsync();
