## 9. TROUBLESHOOTING GUIDE

### Problem: Fonts not loading (looks like default font)
Solution:
  ☐ Check _Layout.cshtml has Google Fonts <link> tag
  ☐ Verify fonts URL: https://fonts.googleapis.com/...
  ☐ Clear browser cache (Ctrl+Shift+Del)
  ☐ Hard refresh (Ctrl+Shift+R)
  ☐ Check DevTools Network tab for 404s on fonts

### Problem: Dark mode toggle not working
Solution:
  ☐ Verify JavaScript at bottom of _Layout.cshtml exists
  ☐ Check browser console for JS errors (F12)
  ☐ Verify localStorage is enabled
  ☐ Check that html element is being updated with data-bs-theme
  ☐ Try: localStorage.clear() in console, then toggle again

### Problem: Seat grid not rendering
Solution:
  ☐ Check seatmap.css is linked in _Layout.cshtml
  ☐ Verify CSS file exists: /wwwroot/css/seatmap.css
  ☐ Check browser console for CSS errors
  ☐ Verify jQuery is loaded before seat selection script
  ☐ Check SelectSeats.cshtml has correct model binding

### Problem: Sample data not seeded
Solution:
  ☐ Verify SampleDataSeeding.cs exists in /Data folder
  ☐ Check Program.cs calls SeedSampleDataAsync
  ☐ Run: $ dotnet ef database drop --force
  ☐ Run: $ dotnet ef database update
  ☐ Run: $ dotnet run
  ☐ Watch console output for seeding messages
  ☐ Check database directly (SQL query)

### Problem: AJAX POST returns 403 Forbidden
Solution:
  ☐ Verify [ValidateAntiForgeryToken] on ReserveSeats action
  ☐ Verify @Html.AntiForgeryToken() in SelectSeats view
  ☐ Verify jQuery includes token in request header
  ☐ Check request includes __RequestVerificationToken parameter

### Problem: Seat selection animation not smooth
Solution:
  ☐ Check browser supports CSS transitions/animations
  ☐ Verify seatmap.css has @keyframes and transitions
  ☐ Check GPU acceleration: Try reducing animation complexity
  ☐ Close other apps consuming CPU
  ☐ Test on different browser

### Problem: Responsive layout breaks on mobile
Solution:
  ☐ Verify meta viewport tag in _Layout.cshtml:
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  ☐ Check Bootstrap is loaded (required for responsive grid)
  ☐ Test on actual mobile device or Chrome DevTools mobile emulator
  ☐ Verify @media queries in seatmap.css for mobile breakpoints
  ☐ Check no fixed widths on container divs
