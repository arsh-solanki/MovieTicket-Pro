IMPORTANT NOTES
═════════════════════════════════════════════════════════════════════════════════

DOUBLE-BOOKING PREVENTION:
  • Unique index on BookedSeat(ShowId, SeatNumber) is CRITICAL
  • Database enforces constraint: only one seat per show can be booked once
  • If second user tries to book same seat: DbUpdateException thrown
  • Handle with try-catch in controller, return "Seat already booked" message

SOFT DELETE QUERIES:
  ✓ CORRECT:
    var activeMovies = await _db.Movies.Where(m => m.IsActive).ToListAsync();

  ✗ WRONG (returns deactivated items):
    var allMovies = await _db.Movies.ToListAsync();

ROLE-BASED ACCESS:
  • Admin: Can CRUD movies, theatres, screens, shows, view bookings/reports
  • User: Can browse movies, book tickets, view booking history
  • Use [Authorize(Roles = "Admin")] on controllers/actions
