────────────────────────────────────────────────────────────────────────────────
User clicks "Reserve Seats" button

jQuery builds request:
{
    "showId": 5,
    "seatNumbers": ["A1", "A2", "B3"]
}

jQuery AJAX POST to /Booking/ReserveSeats
  ├─ URL: /Booking/ReserveSeats
  ├─ Method: POST
  ├─ Content-Type: application/json
  ├─ Headers: RequestVerificationToken (antiforgery)
  └─ Data: JSON.stringify({ showId, seatNumbers })

Server receives [FromBody] ReserveSeatsRequest

BookingController.ReserveSeats() executes:
  ├─ Validate: ShowId exists, not started, seats not empty
  ├─ Get user ID from claims: User.FindFirstValue(ClaimTypes.NameIdentifier)
  ├─ Check availability: Query BookedSeats for conflicts
  ├─ If conflict → return Json(success: false, message: "Seat taken")
  ├─ If available:
  │   └─ Start Database Transaction
  │       ├─ Create Booking record
  │       ├─ Save (get Booking.Id)
  │       ├─ Create BookedSeat records (one per seat)
  │       ├─ Calculate TotalAmount from SeatPrice
  │       ├─ Update Booking.TotalAmount
  │       ├─ Save changes
  │       └─ Commit transaction
  └─ Return Json(success: true, bookingId: X)

CRITICAL SAFETY FEATURES:
  ✓ Database transaction (atomicity: all-or-nothing)
  ✓ Unique index BookedSeat(ShowId, SeatNumber) prevents DB duplicates
  ✓ [Authorize] ensures only logged-in users book
  ✓ [ValidateAntiForgeryToken] CSRF protection
  ✓ User ownership verified (UserId captured at booking)

[HttpPost("ReserveSeats")]
[Authorize]
[ValidateAntiForgeryToken]
public async Task<IActionResult> ReserveSeats([FromBody] ReserveSeatsRequest request)
────────────────────────────────────────────────────────────────────────────────
PURPOSE: Create booking with selected seats (CRITICAL AJAX ENDPOINT)
REQUIRES: Authenticated user, antiforgery token
METHOD: POST with [FromBody] JSON binding
REQUEST: ReserveSeatsRequest { ShowId, List<SeatNumbers> }
RETURNS: Json<ReserveSeatsResponse>

SUCCESS RESPONSE:
{
    "success": true,
    "message": "Booking confirmed successfully",
    "bookingId": 42
}

ERROR RESPONSES:
- Invalid request → success: false, message: "Invalid request"
- Show not found → success: false, message: "Show not found"
- Show started → success: false, message: "Show has already started"
- Seats taken → success: false, message: "Some seats are already booked", 
               errorDetails: "Seats A1, A2 are no longer available"

EXECUTION:
  1. Validate request (ShowId, SeatNumbers not empty)
  2. Get current UserId from claims
  3. Load Show with SeatPrices, BookedSeats
  4. Verify show not started
  5. Check seat availability (race condition protection)
  6. If unavailable → return Json(success: false, ...)
  7. If available → Start transaction
      ├─ Create Booking
      ├─ Create BookedSeat for each seat
      ├─ Calculate TotalAmount
      ├─ Save changes
      ├─ Commit transaction
      └─ Return Json(success: true, bookingId: X)

SAFETY FEATURES:
  ✓ [Authorize] attribute (logged-in users only)
  ✓ [ValidateAntiForgeryToken] (CSRF protection)
  ✓ Database transaction (atomicity)
  ✓ Unique index on BookedSeat(ShowId, SeatNumber) (DB-level safety)
  ✓ Seat availability check before booking
  ✓ User ownership: UserId captured at creation

$(document).on('click', '.seat.available', function() {
    const seatNumber = $(this).attr('data-seat');

    if ($(this).hasClass('selected')) {
        // Deselect
        $(this).removeClass('selected');
        selectedSeats = selectedSeats.filter(s => s !== seatNumber);
    } else {
        // Select
        $(this).addClass('selected');
        selectedSeats.push(seatNumber);
    }

    updateSummary();
});

UPDATE SUMMARY (Real-time):
────────────────────────────────────────────────────────────────────────────────
function updateSummary() {
    // Update seat count display
    $('#seatCount').text(selectedSeats.length);

    // Calculate total price
    let totalPrice = 0;
    selectedSeats.forEach(seat => {
        const category = $(`[data-seat="${seat}"]`).attr('data-category');
        totalPrice += priceMap[category];
    });
    $('#totalPrice').text(totalPrice.toFixed(2));

    // Update selected seats list HTML
    const listHtml = selectedSeats.map(seat => {
        return `<span class="seat-tag">${seat} ×</span>`;
    }).join('');
    $('#selectedSeatsList').html(listHtml);

    // Enable/disable reserve button
    $('#reserveButton').prop('disabled', selectedSeats.length === 0);
}

RESERVE BUTTON CLICK:
────────────────────────────────────────────────────────────────────────────────
$('#reserveButton').click(function() {
    // Build request
    const request = {
        showId: @Model.ShowId,
        seatNumbers: selectedSeats
    };

    // Get antiforgery token
    const token = $('input[name="__RequestVerificationToken"]').val();

    // AJAX POST
    $.ajax({
        url: '/Booking/ReserveSeats',
        type: 'POST',
        contentType: 'application/json; charset=utf-8',
        headers: { 'RequestVerificationToken': token },
        data: JSON.stringify(request),
        success: function(response) {
            if (response.success) {
                // Redirect to confirmation
                window.location.href = '/Booking/Confirmation/' + response.bookingId;
            } else {
                // Show error
                alert('Booking failed: ' + response.message);
            }
        },
        error: function(xhr, status, error) {
            alert('Error: ' + error);
        }
    });
});

LOAD BOOKED SEATS (On page load):

function loadSeatStatus() {

                $(`[data-seat="${seat}"]`)
                    .removeClass('available')
                    .addClass('booked');
            });
        }
    });
}

4. DATABASE TRANSACTION FLOW (Safety)
═════════════════════════════════════════════════════════════════════════════════

Why Transaction is Critical:
──────────────────────────────────────────────────────────────────────────────
Race condition scenario (WITHOUT transaction):
  1. User A checks seat A1: available
  2. User B checks seat A1: available
  3. User A books A1 → DB saved
  4. User B books A1 → Duplicate! (unique index catches this at DB level)

With transaction:
  1. User A starts transaction
  2. Checks seat A1 availability
  3. Books seat A1
  4. Commits transaction (atomic: all-or-nothing)
  → UNIQUE INDEX on BookedSeat(ShowId, SeatNumber) prevents duplicates

Code Implementation:
──────────────────────────────────────────────────────────────────────────────
using (var transaction = await _context.Database.BeginTransactionAsync())
{
    try
    {
        // Create Booking
        var booking = new Booking { ... };
        _context.Bookings.Add(booking);
        await _context.SaveChangesAsync();  // Save to get booking.Id

        // Create BookedSeats
        foreach (var seatNumber in request.SeatNumbers)
        {
            var bookedSeat = new BookedSeat
            {
                BookingId = booking.Id,
                ShowId = request.ShowId,
                SeatNumber = seatNumber,
                ...
            };
            _context.BookedSeats.Add(bookedSeat);
        }

        booking.TotalAmount = totalAmount;
        await _context.SaveChangesAsync();
        
        // COMMIT
        await transaction.CommitAsync();
        
        return Json(new { success = true, bookingId = booking.Id });
    }
    catch (Exception ex)
    {
        // ROLLBACK on error
        await transaction.RollbackAsync();
        return Json(new { success = false, message = "Booking failed" });
    }
}

Safety Layers:
  1. Logical transaction (all queries succeed or all fail)
  2. Database UNIQUE INDEX (prevents duplicate seats)
  3. [Authorize] attribute (only logged-in users)
  4. UserID captured (ownership enforcement)

Why Needed:
────────────────────────────────────────────────────────────────────────────────

requests (e.g., booking from malicious site). Antiforgery token prevents this.
