3. CONTROLLER ACTIONS SUMMARY
═════════════════════════════════════════════════════════════════════════════════

HomeController.Index()
  ├─ HTTP: GET /
  ├─ Auth: None required
  ├─ Logic: Load active movies, map to MovieCardViewModel
  └─ Return: View(List<MovieCardViewModel>)

MoviesController.Index()
  ├─ HTTP: GET /Movies
  ├─ Auth: None required
  ├─ Logic: Load active movies, sort by ReleaseDate DESC
  └─ Return: View(List<MovieCardViewModel>)

MoviesController.Details(int id)
  ├─ HTTP: GET /Movies/Details/{id}
  ├─ Auth: None required
  ├─ Logic: Load movie with future shows, map nested ViewModels
  └─ Return: View(MovieDetailViewModel)

BookingController.SelectSeats(int showId)
  ├─ HTTP: GET /Booking/SelectSeats/{showId}
  ├─ Auth: [Authorize] required
  ├─ Logic: Load show with SeatPrices & BookedSeats, map to SeatSelectionViewModel
  ├─ Validation: Show exists, IsActive, not started
  └─ Return: View(SeatSelectionViewModel)

BookingController.GetSeatStatus(int showId)
  ├─ HTTP: GET /Booking/GetSeatStatus/{showId}
  ├─ Auth: [AllowAnonymous] - no auth required
  ├─ Logic: Load show, return booked seats & prices as JSON
  └─ Return: Json({ success, bookedSeats, categories, message })

BookingController.ReserveSeats([FromBody] ReserveSeatsRequest request)
  ├─ HTTP: POST /Booking/ReserveSeats
  ├─ Auth: [Authorize] + [ValidateAntiForgeryToken]
  ├─ Logic: Validate, check availability, start transaction:
  │   ├─ Create Booking
  │   ├─ Create BookedSeats (one per seat)
  │   ├─ Calculate TotalAmount
  │   ├─ Save & commit
  │   └─ If error: Rollback transaction
  ├─ Validation: ShowId, SeatNumbers not empty, show availability
  └─ Return: Json({ success, message, bookingId or errorDetails })

BookingController.Confirmation(int bookingId)
  ├─ HTTP: GET /Booking/Confirmation/{bookingId}
  ├─ Auth: [Authorize] + ownership check
  ├─ Logic: Load booking, verify user owns it, map to BookingConfirmationViewModel
  ├─ Security: Return Forbid() if user doesn't own booking
  └─ Return: View(BookingConfirmationViewModel) or 403 Forbid

4. JQUERY CODE SNIPPETS
═════════════════════════════════════════════════════════════════════════════════

Initialize Seat Grid:
  function initializeSeatGrid() {
      for (let row = 0; row < 10; row++) {
          let rowLetter = String.fromCharCode(65 + row);  // A-J
          let rowDiv = $('<div class="seat-row">');
          
          for (let col = 1; col <= 15; col++) {
              let seatNum = rowLetter + col;
              let category = rowLetter === 'A' ? 'Premium' : 
                            rowLetter === 'B' ? 'Regular' : 'Economy';
              
              let seat = $(`<div class="seat available" data-seat="${seatNum}" data-category="${category}"></div>`);
              rowDiv.append(seat);
          }
          
          $('#seatGrid').append(rowDiv);
      }
  }

Load Booked Seats:
  function loadSeatStatus() {
      $.getJSON('/Booking/GetSeatStatus/' + showId, function(data) {
          if (data.success) {
              data.bookedSeats.forEach(seat => {
                  $(`[data-seat="${seat}"]`).removeClass('available').addClass('booked');
              });
          }
      });
  }

Seat Click Handler:
  $(document).on('click', '.seat.available', function() {
      let seatNum = $(this).attr('data-seat');
      
      if ($(this).hasClass('selected')) {
          $(this).removeClass('selected');
          selectedSeats = selectedSeats.filter(s => s !== seatNum);
      } else {
          $(this).addClass('selected');
          selectedSeats.push(seatNum);
      }
      
      updateSummary();
  });

Update Summary:
  function updateSummary() {
      $('#seatCount').text(selectedSeats.length);
      
      let total = 0;
      selectedSeats.forEach(seat => {
          let category = $(`[data-seat="${seat}"]`).attr('data-category');
          total += priceMap[category];
      });
      
      $('#totalPrice').text(total.toFixed(2));
      $('#reserveButton').prop('disabled', selectedSeats.length === 0);
  }

AJAX POST Request:
  $('#reserveButton').click(function() {
      const token = $('input[name="__RequestVerificationToken"]').val();
      
      $.ajax({
          url: '/Booking/ReserveSeats',
          type: 'POST',
          contentType: 'application/json',
          headers: {'RequestVerificationToken': token},
          data: JSON.stringify({showId: @Model.ShowId, seatNumbers: selectedSeats}),
          success: function(response) {
              if (response.success) {
                  window.location.href = '/Booking/Confirmation/' + response.bookingId;
              } else {
                  alert('Booking failed: ' + response.message);
              }
          },
          error: function() { alert('Error'); }
      });
  });

Key Tables for Phase 5:
  ├─ Movies
  │   ├─ Id, Title, Description, PosterUrl, DurationMinutes, ReleaseDate, IsActive
  │   └─ Foreign Keys: None
  │
  ├─ Theatres
  │   ├─ Id, Name, City, IsActive
  │   └─ Foreign Keys: None
  │
  ├─ Screens
  │   ├─ Id, Name, TheatreId, SeatLayout, LayoutJson, IsActive
  │   └─ Foreign Keys: TheatreId → Theatres
  │
  ├─ Shows
  │   ├─ Id, MovieId, ScreenId, StartDateTime, EndDateTime, IsActive
  │   └─ Foreign Keys: MovieId → Movies, ScreenId → Screens
  │
  ├─ SeatPrice
  │   ├─ Id, ShowId, Category, Price, IsActive
  │   └─ Foreign Keys: ShowId → Shows
  │
  ├─ Bookings
  │   ├─ Id, UserId, ShowId, BookingDateTime, Status, TotalAmount, IsActive, Notes
  │   └─ Foreign Keys: UserId → AspNetUsers, ShowId → Shows
  │
  └─ BookedSeats
      ├─ Id, BookingId, ShowId, SeatNumber, Category, Price, IsActive
      ├─ Foreign Keys: BookingId → Bookings, ShowId → Shows
      └─ Unique Index: (ShowId, SeatNumber) - Prevents double-booking

7. ERROR CODES & RESPONSES
═════════════════════════════════════════════════════════════════════════════════

200 OK
  ├─ SelectSeats page loaded successfully
  ├─ GetSeatStatus JSON returned
  └─ ReserveSeats success response

400 Bad Request
  ├─ Invalid request body (ReserveSeats)
  ├─ Show has already started
  ├─ Seats already booked
  ├─ Missing antiforgery token
  └─ Invalid ShowId or SeatNumbers

401 Unauthorized
  └─ User not authenticated (redirect to login)

403 Forbidden
  ├─ User doesn't own booking (Confirmation)
  └─ Antiforgery token validation failed

404 Not Found
  ├─ Show not found (SelectSeats)
  ├─ Movie not found (Details)
  └─ Booking not found (Confirmation)

500 Internal Server Error
  ├─ Database transaction error
  ├─ Unhandled exception
  └─ Check logs for details

8. AUTHENTICATION & AUTHORIZATION
═════════════════════════════════════════════════════════════════════════════════

[Authorize] Attribute:
  ├─ Requires user to be logged in
  ├─ Unauthenticated requests: Redirect to /Identity/Account/Login
  ├─ Used on: SelectSeats, ReserveSeats, Confirmation
  └─ Applied at: Class or Method level

[AllowAnonymous] Attribute:
  ├─ Allows unauthenticated access
  ├─ Used on: GetSeatStatus (safe read-only endpoint)
  └─ Overrides class-level [Authorize]

[ValidateAntiForgeryToken] Attribute:
  ├─ Validates CSRF token
  ├─ Token extracted from request headers: RequestVerificationToken
  ├─ Token generated by: @Html.AntiForgeryToken() in form
  ├─ Used on: ReserveSeats POST action
  └─ Missing token: 400 Bad Request

User Identity:
  ├─ Get UserId: User.FindFirstValue(ClaimTypes.NameIdentifier)
  ├─ Get Email: User.FindFirstValue(ClaimTypes.Email)
  ├─ Get Username: User.Identity.Name
  └─ Check authenticated: User.Identity.IsAuthenticated
