 * ═════════════════════════════════════════════════════════════════════════════════
 * UNIQUE INDEXES (PREVENT DATA INTEGRITY ISSUES)
 * ═════════════════════════════════════════════════════════════════════════════════
 * 
 * 1. BookedSeat(ShowId, SeatNumber) – PRIMARY CONSTRAINT
 *    Purpose: Ensures a seat in a show can only be booked once
 *    Behavior: INSERT fails if same (ShowId, SeatNumber) exists
 *    Error Handling: Catch DbUpdateException, return "Seat already booked" message
 *    Why: Prevents race conditions & double-booking simultaneous requests
 * 
 * 2. SeatPrice(ShowId, Category)
 *    Purpose: Each show has only one price per seat category
 *    Behavior: No duplicate (Silver, Gold, etc.) prices per show
 * 
 * 3. Screen(TheatreId, Name)
 *    Purpose: Screen names are unique per theatre (e.g., no two "Screen 1" in same theatre)
 *    Behavior: INSERT fails if theatre already has a screen with same name
 * 
 * 4. Theatre(Name, City)
 *    Purpose: Prevent duplicate theatre entries in same city
 *    Behavior: INSERT fails if (Name, City) combo already exists
 *
