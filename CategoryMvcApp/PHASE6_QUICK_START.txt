## 🔧 Configuration Reference

### Google Fonts
Location: Views/Shared/_Layout.cshtml
```html
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700&family=Montserrat:wght@500;600;700;800&display=swap" rel="stylesheet">
```
- Poppins: Body text (light, regular, medium, semi-bold, bold)
- Montserrat: Headings (medium, semi-bold, bold, extra-bold)

### Dark Mode Toggle
Location: Views/Shared/_Layout.cshtml (footer scripts)
- Button ID: #themeToggle
- LocalStorage key: 'theme'
- Values: 'light' | 'dark'
- HTML attribute: data-bs-theme="light|dark"

### Seat Map CSS
Location: wwwroot/css/seatmap.css
- .seat base: 45×45px, 6px margin
- .available: #28a745 → #1e7e34 gradient
- .selected: #007bff → #0056b3 gradient, pulse animation
- .booked: #343a40, disabled
- Animations: pulse (2s loop), slideInUp (staggered)

### Sample Data Seeding
Location: Data/SampleDataSeeding.cs
- Called automatically in Program.cs
- Creates roles, users, movies, theatres, screens, prices, shows
- Only runs if data doesn't exist (idempotent)

## ❓ FAQ

**Q: How do I test dark mode?**
A: Click the moon icon in the top-right navbar. It toggles to dark mode with a smooth transition.

**Q: Why do I need to refresh after clearing data?**
A: EF Core caches queries. Use: $ dotnet ef database drop --force then $ dotnet ef database update

**Q: How do I modify the sample data?**
A: Edit Data/SampleDataSeeding.cs, then run the app again (seeding is idempotent).

**Q: Can I use a different color scheme?**
A: Yes! Update CSS variables in _Layout.cshtml <style> tag. Look for --primary-gradient, --success-gradient, etc.

**Q: Do the fonts load from CDN?**
A: Yes, Google Fonts CDN. If offline, system fonts fall back to sans-serif.

**Q: Is dark mode supported on all browsers?**
A: Yes! Uses CSS custom properties (data-bs-theme) supported in all modern browsers.

**Q: Can I modify seat prices?**
A: Yes! In SampleDataSeeding.cs, update the prices array (currently Premium 500, Gold 300, Silver 150).

**Q: How do I add more movies?**
A: Add to the movies[] array in SampleDataSeeding.cs SeedMoviesAsync method.

**Q: Why are some seats disabled?**
A: Booked seats (IsActive = true in BookedSeats table) are disabled and appear gray.

## 🚨 Troubleshooting

### Fonts not loading?
→ Check browser Network tab (DevTools F12)
→ Verify fonts.googleapis.com is accessible
→ Clear cache: Ctrl+Shift+Del
→ Hard refresh: Ctrl+Shift+R

### Dark mode not persisting?
→ Check browser console for JS errors
→ Verify localStorage is enabled
→ Try: localStorage.clear() in console, then toggle again

### Sample data not created?
→ Watch console output during startup
→ Check database file exists (LocalDB)
→ Run: $ dotnet ef database drop --force
→ Run: $ dotnet ef database update
→ Run: $ dotnet run (seeding happens automatically)

### Carousel not auto-advancing?
→ Check ViewData and Model are bound correctly
→ Verify JavaScript in Home/Index footer runs
→ Check browser console for JS errors
→ Ensure 4+ movies exist in database

### Seat grid not rendering?
→ Verify seatmap.css is linked in _Layout.cshtml
→ Check file exists: /wwwroot/css/seatmap.css
→ Clear browser cache
→ Open DevTools → Inspector → Check CSS loaded
