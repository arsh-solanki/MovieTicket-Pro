EXAMPLE: UPDATING HomeController.Index WITH PHASE 4 VIEWMODELS
═══════════════════════════════════════════════════════════════════════════════

Current HomeController.cs might look like:

    public class HomeController : Controller
    {
        private readonly ApplicationDbContext _context;

        public HomeController(ApplicationDbContext context)
        {
            _context = context;
        }

        public async Task<IActionResult> Index()
        {
            var movies = await _context.Movies
                .Where(m => m.IsActive)
                .ToListAsync();

            // NOW WITH PHASE 4 VIEWMODELS:
            var vm = movies.Select(m => new MovieCardViewModel
            {
                Id = m.Id,
                Title = m.Title,
                PosterUrl = m.PosterUrl,
                ReleaseDate = m.ReleaseDate,
                Description = m.Description.Length > 100 
                    ? m.Description.Substring(0, 100) + "..." 
                    : m.Description,
                IsActive = m.IsActive
            }).ToList();

            return View(vm);
        }

        public IActionResult Privacy()
        {
            return View();
        }

        [ResponseCache(Duration = 0, Location = ResponseCacheLocation.None, NoStore = true)]
        public IActionResult Error()
        {
            return View(new ErrorViewModel { RequestId = Activity.Current?.Id ?? HttpContext.TraceIdentifier });
        }
    }

KEY POINTS FOR PHASE 4
═══════════════════════════════════════════════════════════════════════════════

1. ViewModels are TRANSFER OBJECTS between Controller and View
   • Don't use Entity models directly in views → use ViewModels
   • ViewModels have only data view needs (lighter, more flexible)

2. DTOs for AJAX are separate (ReserveSeatsRequest/Response)
   • Handles JSON serialization/deserialization
   • Model binding with [FromBody] attribute

3. All ViewModels are strongly-typed
   • Enable @model directive in Razor views
   • Compile-time checking + IntelliSense
   • Safe HTML encoding automatically

4. Data Annotations do 3 things:
   • Validation (Required, StringLength, Range, Url, Regex, etc.)
   • Display (Name, Format, Description for form labels)
   • Mapping ([ForeignKey], [Display], [DataType], etc.)
