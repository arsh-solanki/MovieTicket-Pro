STEP 5: TEST BOOKING WORKFLOW (10 minutes)
═════════════════════════════════════════════════════════════════════════════════

5A. LOGIN (Required for booking)
    ├─ Click "Login" in top-right navbar
    ├─ Register if you don't have account: "Click here to register as a new user"
    └─ Login with your credentials

5B. VIEW MOVIE DETAILS
    ├─ Click any movie card → "View & Book" button
    └─ Expected: Movie details page with future showtimes

5C. SELECT SEATS (THE MAGIC ✨)
    ├─ Click "Book Tickets" on any showtime
    ├─ Expected: Seat grid loads with 10 rows (A-J) × 15 columns (1-15)
    ├─ Green seats = Available (click to select)
    ├─ Red seats = Already booked (cannot select)
    └─ Blue seats = Your selection (click again to deselect)

5D. SELECT 2-3 SEATS
    ├─ Click on available seats (green)
    ├─ Watch sidebar update:
    │   ├─ "Seats selected" count increases
    │   ├─ "Total" amount updates in real-time
    │   └─ Selected seats list shows seat numbers
    └─ "Reserve Seats" button becomes enabled (was disabled before)

5E. SUBMIT BOOKING (AJAX)
    ├─ Click "Reserve Seats" button
    ├─ Open DevTools (F12) → Network tab to watch request
    ├─ Expected: POST request to /Booking/ReserveSeats
    ├─ Expected response: { success: true, bookingId: X }
    └─ Expected: Auto-redirect to confirmation page

5F. VIEW CONFIRMATION
    ├─ Page shows: ✅ "Booking Confirmed!"
    ├─ Displays: Confirmation #, seats, prices, total
    ├─ Shows: "Print Ticket" button
    └─ Success! Your first booking is complete! 🎉

COMMON QUESTIONS
═════════════════════════════════════════════════════════════════════════════════

Q: What if I get compilation errors?
A: Run: $ dotnet clean
   Then: $ dotnet build
   Check error messages and PHASE5_TESTING_GUIDE.txt troubleshooting

Q: What if seat grid doesn't render?
A: • Press F12 in browser
   • Go to Console tab
   • Look for red error messages
   • Check that seed data exists (movies, shows, seat prices)

Q: What if AJAX POST fails?
A: • Check Network tab (F12)
   • Look for request to /Booking/ReserveSeats
   • Check response status and body
   • See PHASE5_TESTING_GUIDE.txt AJAX troubleshooting

Q: How do I see the database?
A: Open SQL Server Management Studio → (localdb)\mssqllocaldb → MovieTicketDb
   Or use Visual Studio's SQL Server Object Explorer

Q: Can I test without login?
A: No, booking requires authentication (by design).
   Register a test account first.

Q: What's the difference between Home/Index and Movies/Index?
A: Both show movies, but Home/Index is the landing page with hero section.
   Movies/Index is an alternative listing page. Both use MovieCardViewModel.

Q: Why does GetSeatStatus not require [Authorize]?
A: It's read-only (no personal data). Safe to expose for loading seat status.
   Creating a booking does require authorization.

ARCHITECTURE AT A GLANCE
═════════════════════════════════════════════════════════════════════════════════

User → Browser → AJAX → Server → Database → Back to Browser

1. User clicks movie → HomeController.Index loads movies
2. User clicks showtime → MoviesController.Details loads shows
3. User clicks "Book Tickets" → BookingController.SelectSeats loads seat page
4. jQuery generates seat grid
5. jQuery calls $.getJSON(/Booking/GetSeatStatus) → Marks booked seats
6. User clicks seats → jQuery updates selection
7. User clicks "Reserve" → jQuery calls $.ajax POST to /Booking/ReserveSeats
8. Server validates, starts transaction, creates booking
9. Server returns JSON with bookingId
10. jQuery redirects to /Booking/Confirmation/{id}
11. BookingController.Confirmation loads and displays booking
12. User sees confirmation page 🎉
