✓ TEST 3.5: Antiforgery Token Validation

Setup:
  1. Open browser DevTools (F12)
  2. Have SelectSeats page loaded

Test Steps:
  1. In DevTools Console, try to make manual AJAX call WITHOUT token:
     $.ajax({
         url: '/Booking/ReserveSeats',
         type: 'POST',
         contentType: 'application/json',
         data: JSON.stringify({showId: 1, seatNumbers: ["A1"]})
         // NO token in headers
     });

  2. Expected: Request fails with 400 Bad Request
  3. Response message: Something like "The required antiforgery token is missing"

  Now try WITH token:
  4. Get token:
     const token = $('input[name="__RequestVerificationToken"]').val();
  5. Make request WITH token:
     $.ajax({
         url: '/Booking/ReserveSeats',
         type: 'POST',
         contentType: 'application/json',
         headers: {'RequestVerificationToken': token},
         data: JSON.stringify({showId: 1, seatNumbers: ["A1"]})
     });
  6. Expected: Request succeeds (or shows seat-not-available error, not token error)

Expected Result:
  ✓ Request without token → 400 Bad Request
  ✓ Request with token → 200 OK (or business logic error, not token error)
  ✓ CSRF protection active

SECTION 7: COMMON ISSUES & TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

ISSUE: Seat grid not rendering
┌─ Cause: jQuery not loaded or error in initializeSeatGrid()
├─ Solution:
│  1. Check F12 Console for JavaScript errors
│  2. Verify jQuery loaded: $ in console → should work
│  3. Check Model.Rows and Model.Columns not null
│  4. Verify @Html.AntiForgeryToken() in view
└─ Fix: Add console.log in jQuery to debug

ISSUE: AJAX POST returns 400 Bad Request
┌─ Cause: Usually antiforgery token validation failure
├─ Solution:
│  1. Verify @Html.AntiForgeryToken() in view
│  2. Verify header: 'RequestVerificationToken': token
│  3. Check token value not empty: console.log(token)
│  4. Verify [ValidateAntiForgeryToken] on action
└─ Fix: Ensure token extraction and header setting correct

ISSUE: Booked seats not showing as unavailable
┌─ Cause: GetSeatStatus AJAX failed or jQuery click handler issue
├─ Solution:
