Step 1: Update HomeController.Index()
────────────────────────────────────────────────────────────────────────────────
using CategoryMvcApp.ViewModels;

public async Task<IActionResult> Index()
{
    var movies = await _context.Movies
        .Where(m => m.IsActive)
        .ToListAsync();

    var vm = movies.Select(m => new MovieCardViewModel
    {
        Id = m.Id,
        Title = m.Title,
        PosterUrl = m.PosterUrl,
        ReleaseDate = m.ReleaseDate,
        Description = m.Description?.Length > 100 
            ? m.Description.Substring(0, 100) + "..." 
            : m.Description,
        IsActive = m.IsActive
    }).ToList();

    return View(vm);
}

⚡ KEY TAKEAWAYS
═════════════════════════════════════════════════════════════════════════════════

1. ViewModels separate Entity models from View requirements
   → Better security, flexibility, maintainability

2. Data Annotations handle both validation and display
   → Reduces boilerplate code in views/controllers

3. Nested ViewModels handle complex data structures cleanly
   → List<SeatCategoryPriceViewModel> in SeatSelectionViewModel

4. DTOs (ReserveSeatsRequest/Response) enable AJAX integration
   → Clean JSON serialization/deserialization

5. Strongly-typed views provide compile-time safety
   → IntelliSense + type checking + HTML encoding automatic
