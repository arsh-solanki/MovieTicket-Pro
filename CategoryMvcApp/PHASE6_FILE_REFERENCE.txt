🎨 **wwwroot/css/seatmap.css** (600+ lines)
   Purpose: Complete seat map styling with animations
   Contains:
     • Seat base styles (.seat, .available, .selected, .booked)
     • Animations (@keyframes pulse, slideInUp)
     • Grid layout (.seat-grid, .seat-row)
     • Screen visual styling
     • Sidebar sticky panel styling
     • Dark mode overrides
     • Responsive design (@media queries)
     • Print styles (@media print)
   Key Features:
     • Available seats: Green gradient (#28a745 → #1e7e34)
     • Selected seats: Blue gradient (#007bff → #0056b3) with pulse
     • Booked seats: Dark gray (#343a40), disabled
     • Smooth animations & transitions
     • Mobile responsive (45px → 35px → 30px)
     • Accessibility: Focus states, proper contrast

🗄️ **Data/SampleDataSeeding.cs** (380+ lines)
   Purpose: Automatic sample data generation on app startup
   Contains:
     • SeedSampleDataAsync() - Main orchestration method
     • SeedRolesAsync() - Creates Admin & User roles
     • SeedUsersAsync() - Creates 5 test users (1 admin, 4 customers)
     • SeedMoviesAsync() - Creates 5 movies with poster URLs
     • SeedTheatresAndScreensAsync() - Creates 2 theatres, 4 screens
     • SeedSeatPricesAsync() - Creates 3-tier pricing (Premium/Gold/Silver)
     • SeedShowsAsync() - Creates 50+ shows for next 7 days
   Data Generated:
     • 5 Test Users (with different roles)
     • 5 Movies (Inception, Dark Knight Rises, Interstellar, etc.)
     • 2 Theatres (PVR Downtown, AMC Midtown)
     • 4 Cinema Screens (IMAX, Dolby, Standard, Premium)
     • 50+ Shows (across 7 days, multiple timings)
     • 3 Pricing Categories (Premium ₹500, Gold ₹300, Silver ₹150)
