───────────────────────────────────────────────────────────────────────────────────
  AUTHENTICATION & AUTHORIZATION EXPLAINED
───────────────────────────────────────────────────────────────────────────────────

AUTHENTICATION (Who are you?)
  • User enters credentials: admin@movie.com / Admin@123!
  • ASP.NET Core Identity validates against hashed password
  • If valid: Creates authentication cookie
  • Cookie sent with every request
  • Middleware reads cookie: User.Identity.IsAuthenticated = true

AUTHORIZATION (What can you do?)
  • Middleware checks: Does user have required role?
  • [Authorize(Roles = "Admin")] checks: Is user in "Admin" role?
  • If YES: Execute action
  • If NO: Show "Access Denied" or redirect to login

TWO-ROLE SYSTEM (Seeded in Phase 2):
  • "Admin" → Can access /Admin/* pages, manage content, view reports
  • "User" → Can browse, search, book tickets (default for new registrations)

FLOW DIAGRAM:

    User visits /Admin/Dashboard
         ↓
    [Authorize(Roles = "Admin")] checks
         ↓
    Is user.Identity.IsAuthenticated? 
         ├─ NO  → Redirect to /Identity/Account/Login?returnUrl=/Admin/Dashboard
         └─ YES → Continue
              ↓
         Is user in "Admin" role?
              ├─ NO  → Show 403 Forbidden (Access Denied)
              └─ YES → Execute DashboardController.Index()
                   ↓
                   Return view with _AdminLayout

───────────────────────────────────────────────────────────────────────────────────
  ROLE-BASED AUTHORIZATION PATTERNS
───────────────────────────────────────────────────────────────────────────────────

PROTECT ENTIRE CONTROLLER (Admin-only):
────────────────────────────────────

    [Area("Admin")]
    [Authorize(Roles = "Admin")]
    public class MoviesController : Controller
    {
        public IActionResult Index() { ... }    // Admin only
        public IActionResult Create() { ... }   // Admin only
        public IActionResult Delete(int id) { ... } // Admin only
    }

PROTECT SINGLE ACTION:
──────────────────────

    [HttpGet]
    [Authorize(Roles = "Admin")]
    public async Task<IActionResult> Reports()
    {
        // Only admin can see reports
    }

REQUIRE AUTHENTICATION (Any Logged-In User):
─────────────────────────────────────────────

    [Authorize]
    public async Task<IActionResult> MyBookings()
    {
        // Both Admin and User roles can access
        // But users should only see their own bookings
    }

ROW-LEVEL SECURITY (Users see only their data):
────────────────────────────────────────────────

    [Authorize]
    public async Task<IActionResult> MyBookings()
    {
        var userId = User.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        var bookings = await _db.Bookings
            .Where(b => b.UserId == userId && b.IsActive)  // ← Filter by user
            .ToListAsync();
        return View(bookings);
    }
