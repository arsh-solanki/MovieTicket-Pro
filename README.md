MovieTicket Pro

A movie ticket management web app built with ASP.NET Core MVC, EF Core and SQL Server.

Features
CRUD for Movies, Theatres, Screens and Shows
Role-based admin access with ASP.NET Core Identity
Tech Stack

C#, ASP.NET Core MVC (.NET 10), Entity Framework Core, SQL Server, Bootstrap 5

Run Locally
Clone the repo and open CategoryMvcApp
Set the connection string in appsettings.Development.json
Run dotnet ef database update
Run dotnet run
Planned

Seat selection, booking with double-booking prevention, booking history, payments.
